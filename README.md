# מגרש תרגול נהיגה

סימולטור נהיגה במבט מלמעלה לתרגול חוקי התנועה בישראל לפני הטסט. נוהגים ברכב בעיר קטנה, ו"בוחן" וירטואלי נותן הוראות ורושם כל עבירה.

## איך מריצים
פותחים את `index.html` בדפדפן (כרום / פיירפוקס / אדג'). אין צורך בהתקנה.

## מה יש במגרש
- **רמזורים** (כולל אדום-צהוב) בשלושה צמתים
- **כיכר** עם ארבע יציאות
- **תמרורי "עצור"**, כולל צומת "עצור" מכל הכיוונים
- **תן זכות קדימה** בכניסה מרחוב צדדי
- **רחובות חד-סטריים** עם תמרור "אין כניסה"
- **כבישים דו-נתיביים** עם חצים בנתיבים וקו רצוף לפני הצומת
- **מעברי חציה** עם הולכי רגל, ואזור בית ספר (30 קמ"ש)
- **מהירויות שונות**: 30 / 40 / 50 / 60 / 70 / 80
- **תנועה**: רכבים אחרים שעוצרים ברמזורים, מאותתים ונותנים זכות קדימה

## שליטה
| מקש | פעולה |
|---|---|
| ↑ / W | גז |
| ↓ / S | בלם (החזקה בעצירה מעבירה להילוך אחורי) |
| ← → / A D | הגה |
| Q / E | איתות שמאלה / ימינה |
| C | החלפת מצלמה (מאחורי הרכב / צפון למעלה) |
| R | חזרה לנקודת ההתחלה |
| + / − | זום |
| P | השהיה ועזרה |

בטלפון או בטאבלט מופיעים כפתורי מגע.

עבירה רגילה: −5 נקודות. עבירה חמורה: −15 נקודות ונחשבת כישלון. בלחיצה על "סיום מבחן" מקבלים סיכום.

## מבנה הקוד
- `js/world.js`: מפת הכבישים, גיאומטריה ורמזורים
- `js/traffic.js`: רכבים אחרים והולכי רגל
- `js/player.js`: הפיזיקה של הרכב שלך
- `js/rules.js`: הבוחן: בדיקת חוקים והוראות
- `js/render.js`: ציור המפה, התמרורים והרכבים
- `js/main.js`: לולאת המשחק, מקלדת ולוח המחוונים
