# מגרש תרגול נהיגה

סימולטור נהיגה במבט מלמעלה לתרגול חוקי התנועה בישראל לפני הטסט. נוהגים ברכב בעיר קטנה, ו"בוחן" וירטואלי נותן הוראות ורושם כל עבירה.

## איך מריצים
**הדרך הקלה:** מורידים את הקובץ [`dist/driving-practice.html`](dist/driving-practice.html) (או מהמהדורה האחרונה ב-[Releases](../../releases/latest)), ולוחצים עליו פעמיים. הקובץ מכיל הכל ועובד גם בלי אינטרנט.

**מהקוד:** פותחים את `index.html` בדפדפן (כרום / פיירפוקס / אדג'). אין צורך בהתקנה.

> שים לב: שמירה של דף האתר (Ctrl+S) לא שומרת את המשחק. צריך להוריד את הקובץ מכאן.

## נהיגה מסייעת (ברירת המחדל)
הרכב מחזיק את הנתיב לבד, ואתה מתמקד בחוקים:
- **גז ובלם** (↑ ↓): לשמור על המהירות, להאט לפני פניות, לעצור ב"עצור" וברמזור.
- **איתות** (← → או Q E):
  - בכביש עם כמה נתיבים: איתות של שנייה מעביר נתיב אחד לכיוון האיתות.
  - לפני צומת: איתות שמאלה = פנייה שמאלה, ימינה = פנייה ימינה, בלי איתות = ישר. בצומת T בלי איתות הרכב עוצר בקו ומחכה שתבחר.
  - בכיכר: הרכב מקיף עד שאתה מאותת ימינה, ויוצא ביציאה הבאה.
- היגוי ידני עדיין זמין: מקש **G** או כפתור "היגוי".

## מה יש במגרש
- **רמזורים** (כולל אדום-צהוב) בשלושה צמתים
- **כיכר** עם ארבע יציאות
- **תמרורי "עצור"**, כולל צומת "עצור" מכל הכיוונים
- **תן זכות קדימה** בכניסה מרחוב צדדי
- **רחובות חד-סטריים** עם תמרור "אין כניסה"
- **כבישים דו-נתיביים** עם חצים בנתיבים וקו רצוף לפני הצומת
- **מעברי חציה** עם הולכי רגל, ואזור בית ספר (30 קמ"ש)
- **מהירויות שונות**: 30 / 40 / 50 / 60 / 70 / 80
- **תנועה**: רכבים אחרים שעוצרים ברמזורים, מאותתים ונותנים זכות קדימה

## שליטה
| מקש | פעולה |
|---|---|
| ↑ / W | גז |
| ↓ / S | בלם (בהיגוי ידני: החזקה בעצירה מעבירה להילוך אחורי) |
| ← → / A D | איתות שמאלה / ימינה (בהיגוי ידני: הגה) |
| Q / E | איתות שמאלה / ימינה |
| G | היגוי אוטומטי / ידני |
| C | החלפת מצלמה (מאחורי הרכב / צפון למעלה) |
| R | חזרה לנקודת ההתחלה |
| + / − | זום |
| P | השהיה ועזרה |

בטלפון או בטאבלט מופיעים כפתורי מגע.

## הוספת מפות עם Gemini
1. בתוכנה: **מפות** ← **העתק הנחיות ל-Gemini** (או העתק את [`docs/gemini-prompt.md`](docs/gemini-prompt.md)).
2. מדביקים בצ'אט חדש ב-Gemini, וכותבים בסוף איזו מפה רוצים. כדי להרחיב מפה קיימת: **העתק את המפה הנוכחית** ומדביקים גם אותה.
3. מעתיקים את כל התשובה, מדביקים בתיבה ולוחצים **בדוק וטען**. אם יש שגיאות, התוכנה מכינה בקשת תיקון להדביק חזרה ל-Gemini.

המפות נשמרות בדפדפן. אפשר גם לטעון קובץ `.json`.

## הוספת חוקים לבוחן עם Gemini (תוספים)
1. בתוכנה: **תוספים** ← **העתק הנחיות לתוספים** (או העתק את [`docs/gemini-plugin-prompt.md`](docs/gemini-plugin-prompt.md)).
2. מדביקים ב-Gemini וכותבים בסוף אילו חוקים להוסיף. אפשר להדביק רשימה שלמה של עבירות.
3. מעתיקים את התשובה, מדביקים בתיבה ולוחצים **בדוק והוסף**. התוסף נבדק מיד; אם יש שגיאה, מקבלים בקשת תיקון מוכנה.

תוספים עובדים בקובץ שהורדת למחשב (ובהרצה מהקוד), אבל לא בגרסה שפתוחה באתר claude.ai.

## מבנה הקוד
- `js/world.js`: מפת הכבישים, גיאומטריה ורמזורים
- `js/traffic.js`: רכבים אחרים והולכי רגל
- `js/maps.js`: המפות המובנות ובדיקת התקינות של מפה
- `js/prompt.js`: ההנחיות ל-Gemini (מפות ותוספים)
- `js/player.js`: הפיזיקה של הרכב שלך
- `js/autopilot.js`: הנהיגה המסייעת (שמירת נתיב ובחירת כיוון לפי האיתות)
- `js/plugins.js`: מנוע התוספים והחיישנים שלהם
- `js/rules.js`: הבוחן: בדיקת חוקים והוראות
- `js/render.js`: ציור המפה, התמרורים והרכבים
- `js/main.js`: לולאת המשחק, מקלדת ולוח המחוונים

## בנייה ומהדורה
`node tools/build.js` בונה את `dist/driving-practice.html` (קובץ יחיד) ואת המסמכים שב-`docs/`.
מהדורה חדשה: דוחפים תגית `v*` (למשל `v1.1.0`), ו-GitHub Actions בונה ומפרסם אותה אוטומטית.
